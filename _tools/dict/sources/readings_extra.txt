# 补充读音表（curated）

# 为什么需要这份表：
#   官方字表（《通用规范汉字表》kTGHZ2013 + kMandarin_8105）只收规范读音，
#   而日常口语里存在大量"大家都这么念、字表不认"的常读/俗读。
#   最典型的一条：么 官方读音只有 me，于是「什么」只有 shen'me（743663）一条路径；
#   而实际输入时 shen'mo（743666）才是更常见的手感——结果是整串 98674466
#   （做·什么）在词库里**完全不可达**，连候选都出不来。
#
# 格式：字 <TAB> 读音[,读音...]
#   只**追加**到该字读音列表末尾，不改变语料投票决定的主读音
#   （所以「的」仍旧是 de 打头，不会因为这里列了 di 就跑前面）。
#
# 加词规则：只加"官方确实未收、但日常输入必然要打"的读音。
#   官方已收的异读不必写（例：血 xiě/xuè、谁 shéi/shuí、得 dé/de/děi、
#   地 de/dì、的 de/dī/dí/dì、咯 gē/kǎ/lo/luò —— 都在 kTGHZ2013 里）。
