# 现代口语高频词表（curated source / 一行一词，自上而下频次递减）
#
# 为什么需要这份表：
#   现用《现代汉语常用词表》偏书面语与百科，对口语、问候、应答、口头结构收录极差——
#   实测「你好/您好/好的/在吗/是的/做什么/干什么」等全部落空。这类词靠"事后补丁表"永远补不完。
#
# 排序即频次档：流水线用 Zipf 分布按行号折算 logp，越靠前概率越高。
# 因此请保持"自上而下频次递减"的粗略有序，不要把生僻词插到前面。
#
# 怎么加词：直接把词追加到语义最接近的分组里；同组内不必严格排序。
