# 结构化组合词表（curated）
#
# 为什么需要这份表：
#   《现代汉语常用词表》和 cn_words 这类词表**系统性地不收录"可推导的组合词"**——
#   星期X、X月、X点、第X个、X年、X个这类。它们不是生僻词，而是汉语里最高频的一批词，
#   却因为"看起来能由字拼出来"而全都落空。实测（修复前）：
#     星期一 -23.0 / 星期五 -25.8 / 星期六 完全缺失 / 一年 缺失 / 两点 缺失 / 第一个 缺失
#   后果不是"排得靠后"，而是打 xingqiyi 时让「邢其毅」压过「星期一」。
#
# 排序即频次档 ------ 这一行是这份表最重要的约束。
#   流水线把**表内序位**按 Zipf 折算成概率份额（1/(rank+k)），所以顺序不是"排版"，
#   是权重本身。表越短，每个词分到的份额越大：本表只有约 150 词，
#   若把「八年」误放到前部，它会压过 5.6 万词表里靠真实语料排出来的「报告」。
#   （实测：weight=0.10 时「八年」-8.21 压过「报告」-8.46。这就是顺序的威力。）
#   因此：越常用的越靠前，机械枚举出来的长尾（八年/七年/六点/第二名）一律放最后。
#
# 这份表只覆盖"机械可枚举"的高频组合；更彻底的方案是让无证据词的回退
# 从"字符 unigram 连乘"升级为"字符 bigram 链"，见 OVERHAUL_PLAN.md 阶段 4c。
